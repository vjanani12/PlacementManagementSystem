# 🎓 Placement Management System

A robust, enterprise-grade Java application designed to automate student placement tracking and data management with persistent MySQL database storage.

## 🚀 Key Features
* **Complete CRUD Operations:** Add, search (by ID or Department), view, update, and delete student records.
* **Database Integration:** Powered by **MySQL** using **JDBC**.
* **Layered Architecture:** Clear separation of concerns (Controller, Service, Repository, Model, Util).

## 🛠️ Technologies Used
* **Language:** Java (JDK 21)
* **Database:** MySQL Server
* **Build Tool:** Apache Maven
